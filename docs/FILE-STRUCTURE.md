# File Structure

```
SportsPred/
├── README.md                  Overview, screenshots, links
├── SportsPred.md              Project brief, decisions and changelog
├── requirements.txt           Python dependency (numpy)
├── .github/workflows/
│   └── update.yml             Every 3 hours: test, build, publish to GitHub Pages
├── pipeline/                  Python: data → ratings → simulations → site/data
│   ├── build.py               Entry point (python3 -m pipeline.build); writes index.json and model.json
│   ├── config.py              Competitions covered (incl. World Cup qualifying), tennis surfaces by name, history range, simulation counts, name aliases
│   ├── common.py              HTTP fetching, JSON files, dates
│   ├── soccer_data.py         ESPN soccer results and fixtures, group tables, international archive
│   ├── soccer_model.py        Soccer Elo, goals model, accuracy scoring
│   ├── soccer_sim.py          Monte Carlo: league tables, UEFA league phase, groups, knockouts
│   ├── soccer_build.py        Club and international predictions, odds-over-time replays
│   ├── tennis_data.py         ESPN ATP and WTA singles draws, results and rankings
│   ├── tennis_model.py        Tennis Elo (overall + per-surface), best-of-five conversion, draw and Finals simulation
│   ├── tennis_build.py        Tournament predictions and replays
│   └── live_log.py            Each day's published odds, kept alongside the replay
├── tests/
│   └── test_models.py         Unit tests for models and simulators (no network)
├── data/                      Cached history (finished years and events), reused between runs
│   ├── soccer/<league>/<year>.json
│   ├── soccer/international_results.csv
│   └── tennis/<tour>/<event>.json
├── site/                      The static website (published as-is)
│   ├── index.html             Home: every competition
│   ├── competition.html       One competition: chart, odds table, matches
│   ├── how.html               How the predictions work, plus accuracy
│   ├── assets/app.css         All styles, light and dark themes
│   ├── assets/app.js          Shared: header, settings (⌘,), feedback tab, tags, formatting
│   ├── assets/index.js        Home page logic
│   ├── assets/competition.js  Competition page logic and chart
│   ├── assets/icon.svg        Favicon
│   └── data/                  Generated by the build (not committed)
│       ├── index.json         One summary per competition
│       ├── model.json         Fitted parameters and accuracy
│       ├── soccer/<slug>.json
│       └── tennis/<tour>-<event>.json
└── docs/
    ├── INSTRUCTIONS.md        Setup, run, use
    ├── SYSTEM-DESIGN.md       Architecture and design decisions
    ├── FILE-STRUCTURE.md      This file
    └── images/                README screenshots
```
